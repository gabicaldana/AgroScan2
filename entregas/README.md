# Entregas

Esta pasta concentra os registros das entregas avaliativas do projeto. Use esses documentos para identificar o que foi submetido, qual sprint originou a entrega, quais critérios foram atendidos e quais evidências sustentam a avaliação.

Cada entrega deve preservar a rastreabilidade por evidências, reunindo links para artefatos, documentos, `issues`, `pull requests`, validações e demais registros que permitam verificar o escopo apresentado e o resultado alcançado.

Atualize um registro sempre que houver submissão parcial, revisão avaliativa, reapresentação ou consolidação de resultado relevante para a disciplina.

## Por que há reapresentação

Os Artefatos 1 e 2 foram produzidos em formato anterior e precisaram ser
refeitos após a redefinição do formato das entregas pela disciplina. As
reapresentações também corrigem inconsistências identificadas na revisão:

| Artefato | Correção principal |
| --- | --- |
| 1 | Público-alvo primário: de "engenheiros agrônomos e técnicos agrícolas" para **pequeno produtor de hortaliças**, com o agrônomo passando a usuário secundário |
| 2 | Histórias de usuário preenchidas (estavam vazias); total de pontos corrigido de 152 para **172**; sprints realinhadas e estendidas aos dois bimestres; dois riscos acrescentados |
| 3 | Acrescentados os quatro componentes ausentes; corrigida a apresentação do caderno de campo como funcionalidade futura, quando já está implementado |
